# Issue #20 タグ定義・参照の検証

実施日: 2026-11-01。基点: `develop` の `c5a636c`（PR #43）。共有作業ツリーを使わず、`output/issue-20-work/repo` の独立クローンで実装・検証した。

## 変更と検査経路

`src/data/tags.ts` の定義を `[固定名, 表示名]` の配列へ変更した。モジュール読み込み時に各固定名を正規表現で検証し、既に登録された固定名なら、後の表示名を代入する前に失敗する。既存の `tags`・`tagLabel` の利用側はそのまま使う。記事の未定義参照エラーには参照先を追加した。記事内の重複除去は既存の共通スキーマを維持している。

定義の例: `src/data/tags.ts: 固定名が重複しています: "typescript"`。形式違反では同じファイル名と問題の固定名、`固定名の形式が不正です` を示す。記事の参照違反ではAstroが記事ファイル名と `tags` の位置を表示し、メッセージに `未定義のタグです: unknown-tag` を含める。

## 受け入れ条件と検証方法

`pnpm test:tags` の前半（`scripts/check-tag-data.mjs`）は実際のAstroコレクションとビルドを使う。終了時に定義と一時記事・ページを復元・削除する。生成物はGit管理外の `test-results/` に置き、PRには含めない。同じチェックアウト内で他の編集・ビルドと同時実行しない。

| 要件・受け入れ条件                               | 検証                                                                                                                                                           |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 分類はタグだけ、定義は一か所、記事は固定名で参照 | `src/data/tags.ts` をコレクション・画面が共用。カテゴリや記事種別は追加していない                                                                              |
| 複数タグ・タグなし・省略時の空配列               | 公開・下書きそれぞれで実コレクションの配列を照合                                                                                                               |
| 同一記事内の重複除去と順序                       | `[astro, typescript, astro, typescript]` が両状態で `[astro, typescript]` になることを照合                                                                     |
| 日本語・C++表示名と改名                          | `TypeScript` を `日本語 C++` へ一時変更。新しい検査記事・既存の `automation`・タグ一覧・タグページに反映し、記事の参照を書き換えず `/tags/typescript/` を維持  |
| 未定義参照は下書きも拒否                         | 両状態で `[astro, unknown-tag, unknown-tag]` を入力。重複した未定義参照も省略せず、記事ファイル名と参照先付きでビルド失敗                                      |
| 固定名の形式違反                                 | 空文字、大文字、日本語、C++、空白、アンダースコア、先頭・末尾・連続ハイフン、スラッシュを入力し、定義ファイル名・固定名・原因を含むビルド失敗を確認            |
| 定義重複は上書き前に拒否                         | `astro` の定義位置へ2つ目の `typescript` と異なる表示名を入力し、ビルド・検査の非0終了と定義ファイル名・固定名・重複の原因を照合                               |
| 公開対象と画面の接続                             | 公開記事からタグへのリンクとタグから記事へのリンクを生成物で照合。未使用タグ・下書き専用タグのページと一覧掲載がなく、下書き本文ページも生成されないことを確認 |
| ページ送り等の既存動作                           | 後半の既存 `scripts/check-tags.mjs` で10/11件の境界、複数タグ、件数、安定順、ページ送りURL、下書き専用タグ除外を確認                                           |
| 追加・改名・付け外し手順                         | [README](../../README.md#タグを編集する) に例、検査コマンド、削除時の参照解除、プレビュー手順を記録                                                            |

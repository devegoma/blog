# 個人ブログ

本人の学習の記録を記事として積み重ねるブログ。

## 用語

**記事**:
読んだ記事や本から得た学び、ツールなどを使った経験をまとめた、一つの記録。

**執筆者**:
このブログの記事を書く本人。このブログの執筆者は一人。

**タグ**:
記事を探す手がかりとして付ける名前。本やツール、言語などの名前を使い、一つの記事に複数付けられる。

**タグ表示名**:
読者に見せるタグの名前。同じタグの表示名を変えても、過去記事を含めて同じタグとして扱う。

**タグの URL 用固定名**:
タグページの URL を決める名前。タグ表示名を変更しても維持する。

**説明文**:
執筆者が任意で指定する、その記事の内容を短く紹介する文章。

**概要**:
RSS や SNS 共有で記事を紹介する短い文章。執筆者の説明文があればそれを使い、なければ記事本文などから補う。

**下書き**:
執筆途中などの理由で、読者には公開していない記事。

**公開状態**:
記事を下書きとして扱うか、公開対象として扱うかの指定。指定がない場合は下書きとして扱う。

サイト名は devegoma's blog、公開 URL は https://blog.devegoma.com/ に決定済み。
記事 URL は /posts/<固定名>/、日付は YYYY-MM-DD・日本時間に決定済み。
初回の記事分類はタグのみとし、固定の記事種別・カテゴリは設けない。
公開対象記事の未来の公開日はビルドエラーとし、初回は予約公開を設けない。
RSS は概要と記事へのリンクを掲載し、全文は掲載しない。
概要は説明文を優先し、省略時はコード・表を除いた本文冒頭の文章から最大120文字、抽出不可なら記事タイトルを使う。
更新日は任意・未入力時は非表示とし、公開対象の記事で入力する場合は公開日以降かつ日本時間のビルド日以前とする。
記事一覧は公開日の降順、同日なら記事の URL 用固定名の昇順とし、更新日では並び替えない。
タグは一か所に定義し、記事から固定名で参照する。未定義の参照は検証エラーとする。
タグ URL は /tags/<固定名>/、固定名は小文字の半角英数字をハイフンでつなぐ形式とする。
公開状態の指定漏れは下書きとし、明示的に公開した記事だけを公開する。
下書きはタイトルだけ必須とし、入力済み項目の形式・タグ参照は検証する。未来の公開日を許可する。
記事の削除・下書きへの差し戻しは次の公開で公開出力から除外し、元の記事 URL は404にする。
公開記事が0件のタグは一覧に掲載せず、タグページも生成しない。
固定名未入力の下書きはファイル名から手元専用の仮 URL を作ってプレビューし、公開時は固定名の明示を必須とする。
下書きの日付は形式のみ検証し、日付の前後関係・未来日の制限は公開対象になった時点で適用する。
トップ・タグ別の記事一覧は1ページ10件でページ送りを提供し、RSS は同じ順序で最新20件の公開記事を掲載する。

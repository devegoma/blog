### 共通

- ダーク表示はチャコールの背景とカード、明るいシアンのアクセントを使用する。
- ライト表示は青みのある薄いグレーの背景、白いカード、濃いチャコールの文字、深いシアンのアクセントを使用する。画像は配色の基準であり、実装用の色値は実装時にコントラストを確認して調整する。
- 巨大な太いサンセリフ体のワードマークはダーク表示では白、ライト表示では濃いチャコールとし、黄色いアポストロフィは共通にする。ロゴの上下に余白を設け、背景画像や導入文は置かない。
- 本文は DM Sans + Noto Sans JP、日付などのメタ情報は IBM Plex Mono を使用する。日本語の見出しを欧文ロゴと同じサイズにしない。
- RSS・GitHub・X の3リンクをショートプロフィール内にまとめる。表示はアイコンのみで、文字ラベルを付けない。実装では各リンクにアクセシブル名を設定する。
- 記事は新しい順。タグを手がかりに記事を探せる構成とする。
- 記事一覧の背景は一枚の連続した面にまとめ、各記事の間を細い横罫線で区切る。記事ごとの外枠・角丸・カード間の隙間は設けず、一覧全体の外枠と角丸だけを使用する。各記事には十分な上下余白を設ける。
- ライト表示の記事一覧は白い共通背景と薄いブルーグレーの罫線、ダーク表示はチャコールの共通背景と控えめなブルーグレーの罫線を使用する。サイドバーのプロフィール・ナビゲーション・タグは独立したカードを維持する。

### PC

- 左サイドバーを「ショートプロフィール → ナビゲーション → タグ → ライト・ダーク切り替え」の順に配置する。
- ナビゲーションは「記事」「タグ」「このブログについて」。ページ最上部には置かない。
- 右側に記事一覧を配置し、各記事のサムネイルを表示する。

### モバイル

- ナビゲーションはヘッダーロゴの下に配置し、右揃えにする。
- タグは記事一覧の上に配置する。
- ショートプロフィールは記事一覧の下に配置する。
- 記事一覧のサムネイルは表示せず、タイトルと要約の幅を優先する。

### ライト・ダーク切り替え

- ライト・ダークを切り替えるボタンを設ける。
- PC ではタグ欄の下に配置する。タグカードの外側に余白を取り、左端を揃える。
- 最新の PC 画像にボタンを反映済み。ダーク時は太陽、ライト時は月を表示し、ヘッダーにはボタンを置かない。
- モバイルでの配置は未確定。
- ライト表示中は月アイコン、ダーク表示中は太陽アイコンを表示する。実装では「ダークモードに切り替える」「ライトモードに切り替える」のように操作先を示すアクセシブル名を付ける。
- ボタンはキーボードで操作でき、フォーカス位置が見えるようにする。タップ領域は44px以上を目安とする。
- PC の配置と形状は確定画像を基準とする。初回表示のモードと選択の保存方法は未確定。ライトのモバイル画像は未作成。

### ロゴ単体ファイル

- 参考画像の「Beyond.」のような、太く均一な線と詰めた字間のサンセリフ体を使用する。サイト名と黄色いアポストロフィは維持する。具体的な書体は未確定。
- ダーク背景用：[wordmark-dark.png](./logo/wordmark-dark.png)（白い文字・黄色いアポストロフィ、ダーク背景付き PNG）。白い文字の透過書き出しで縁に乱れが出たため、背景付きで保存する。
- ライト背景用：[wordmark-light.png](./logo/wordmark-light.png)（濃いチャコールの文字・黄色いアポストロフィ、透過 PNG）。
- 組み込みの ImageGen で「PC 画像の太いサンセリフ体ロゴを単独画像として書き出し、ライト用は濃いチャコールの文字と透明背景、ダーク用は白い文字と均一なダーク背景にする。黄色いアポストロフィは維持する」と指示して生成した。ライトの PC 画像は「新ロゴ・配置を維持し、採用済みライト配色に変更、タグ下は月アイコン」と指示して生成した。
- 画像はデザイン素材。SVG のパスデータやフォントファイルは含まない。

### 実装との区別

最終 PC 画像は組み込みの ImageGen で「既存のロゴ・サイドバー・記事内容・サムネイル・タグ下の切り替えボタンを維持し、記事一覧だけを一枚の共通背景にまとめ、記事間を2本の細い横罫線で区切る」と指示し、ライト・ダークを個別に生成した。

画像は画面デザインの基準であり、サイト実装の完了を示さない。記事タイトル・日付・説明文は表示確認用のサンプル。正式なプロフィール文、アバターの元データ、各リンク先 URL は公開準備時に確認する。

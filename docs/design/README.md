# 画面デザイン

サイト全体の画面デザインを管理する。ホーム以外の画面も、このディレクトリで検討・記録する。

## ホーム画面の採用仕様（2026-10-30 検索付きヘッダー）

今回の改修では、[PC・ライト](../../output/zenn-header-trial/desktop-light-search.png)、[PC・ダーク](../../output/zenn-header-trial/desktop-dark-search.png)、[モバイル・ライト](../../output/zenn-header-trial/mobile-light-search.png)、[モバイル・ダーク](../../output/zenn-header-trial/mobile-dark-search.png)を基準とする。配置と配色については、この節を以下の旧デザインより優先する。

- PC は上段左にコンパクトな文字ロゴ、右に検索欄と配色切り替え、下段に左揃えのナビゲーションを置く。本文は左にプロフィールとタグ、右に記事一覧を置く。
- 899px以下はモバイル配置とし、上段にロゴ・検索アイコン・配色切り替え、下段に「記事」「タグ」「このブログについて」を置く。本文は横型プロフィール、記事一覧、タグの順にする。
- PC・モバイルともに記事画像を16:9で表示する。モバイルは文章右側に小さく置く。記事一覧は一枚の背景と横罫線を維持する。
- 検索は準備中の UI とし、入力・送信は無効にする。モバイルの検索アイコンで欄を開き、閉じるボタンへフォーカスする。閉じる操作または Escape で閉じ、検索アイコンへフォーカスを戻す。
- 配色切り替えはヘッダー右端。OS 設定への追従、手動選択の優先と保存、保存不可時の動作は維持する。
- ライトは従来の淡いグレーと白、ダークは濃紺の背景とパネル、明るい青緑のアクセントを使う。ロゴの黄色いアポストロフィー、既存フォントと独立した記事画像を維持する。
- プロフィールは現在の表示確認用データとイニシャルを使う。生成画像内のアバターを切り出して実装しない。

実装と検証の進捗は [作業計画](../work-plan.md) の最新セクションで管理する。検索処理・本番素材・公開準備は完了に含めない。

検索付きヘッダーと新しいモバイル配置を実装し、Chromium の1280・1920・390pxで18テストが成功した。実装の [PC・ライト](../../output/zenn-header-implementation/1440-light.png)・[PC・ダーク](../../output/zenn-header-implementation/1440-dark.png)・[モバイル・ライト](../../output/zenn-header-implementation/390-light.png)・[モバイル・ダーク](../../output/zenn-header-implementation/390-dark.png)を保存した。Firefox は Windows の起動エラーで未検証。全体の Lint・整形は、対象外の既存作業ファイルのエラーが残る。

### 共通

- ダーク表示はチャコールの背景とカード、明るいシアンのアクセントを使用する。
- ライト表示は青みのある薄いグレーの背景、白いカード、濃いチャコールの文字、深いシアンのアクセントを使用する。画像は配色の基準であり、実装用の色値は実装時にコントラストを確認して調整する。
- 巨大な太いサンセリフ体のワードマークはダーク表示では白、ライト表示では濃いチャコールとし、黄色いアポストロフィは共通にする。ロゴの上下に余白を設け、背景画像や導入文は置かない。
- 本文は DM Sans + Noto Sans JP、日付などのメタ情報は IBM Plex Mono を使用する。日本語の見出しを欧文ロゴと同じサイズにしない。
- RSS・GitHub・X の3リンクをショートプロフィール内にまとめる。表示はアイコンのみで、文字ラベルを付けない。実装では各リンクにアクセシブル名を設定する。
- 記事は新しい順。タグを手がかりに記事を探せる構成とする。
- 記事一覧の背景は一枚の連続した面にまとめ、各記事の間を細い横罫線で区切る。記事ごとの外枠・角丸・カード間の隙間は設けず、一覧全体の外枠と角丸だけを使用する。各記事には十分な上下余白を設ける。
- ライト表示の記事一覧は白い共通背景と薄いブルーグレーの罫線、ダーク表示はチャコールの共通背景と控えめなブルーグレーの罫線を使用する。サイドバーのプロフィール・ナビゲーション・タグは独立したカードを維持する。

### PC

- 左サイドバーを「ショートプロフィール → ナビゲーション → タグ → ライト・ダーク切り替え」の順に配置する。
- ナビゲーションは「記事」「タグ」「このブログについて」。ページ最上部には置かない。
- 右側に記事一覧を配置し、各記事のサムネイルを表示する。
- サムネイルはライト・ダークともに横16:縦9の比率で統一する。PC の表示目安は320×180pxとし、表示幅に応じて比率を保ったまま縮小する。画像を縦横別々に引き伸ばさない。
- サムネイルの上下に20px以上の余白を取り、記事の行は画像と文章が収まる高さにする。画像の高さを優先して行と区切り線の位置を調整し、浅い横長の枠に押し込まない。

### モバイル

- ナビゲーションはヘッダーロゴの下に配置し、右揃えにする。
- タグは記事一覧の上に配置する。
- ショートプロフィールは記事一覧の下に配置する。
- 記事一覧のサムネイルは表示せず、タイトルと要約の幅を優先する。

### ライト・ダーク切り替え

- ライト・ダークを切り替えるボタンを設ける。
- PC ではタグ欄の下に配置する。タグカードの外側に余白を取り、左端を揃える。
- 最新の PC 画像にボタンを反映済み。ダーク時は太陽、ライト時は月を表示し、ヘッダーにはボタンを置かない。
- モバイルでもタグ欄の下に配置する。
- ライト表示中は月アイコン、ダーク表示中は太陽アイコンを表示する。実装では「ダークモードに切り替える」「ライトモードに切り替える」のように操作先を示すアクセシブル名を付ける。
- ボタンはキーボードで操作でき、フォーカス位置が見えるようにする。タップ領域は44px以上を目安とする。
- PC の配置と形状は確定画像を基準とする。初回は OS の配色設定を使用し、手動選択を優先して保存する。保存できない場合もその画面で切り替え可能とする。手動選択がない間は OS の設定変更に追従する。

### ロゴ単体ファイル

- 参考画像の「Beyond.」のような、太く均一な線と詰めた字間のサンセリフ体を使用する。サイト名と黄色いアポストロフィは維持する。具体的な書体は未確定。
- ダーク背景用：[wordmark-dark.png](./logo/wordmark-dark.png)（白い文字・黄色いアポストロフィ、ダーク背景付き PNG）。白い文字の透過書き出しで縁に乱れが出たため、背景付きで保存する。
- ライト背景用：[wordmark-light.png](./logo/wordmark-light.png)（濃いチャコールの文字・黄色いアポストロフィ、透過 PNG）。
- 組み込みの ImageGen で「PC 画像の太いサンセリフ体ロゴを単独画像として書き出し、ライト用は濃いチャコールの文字と透明背景、ダーク用は白い文字と均一なダーク背景にする。黄色いアポストロフィは維持する」と指示して生成した。ライトの PC 画像は「新ロゴ・配置を維持し、採用済みライト配色に変更、タグ下は月アイコン」と指示して生成した。
- 画像はデザイン素材。SVG のパスデータやフォントファイルは含まない。

### 実装との区別

更新前の PC 画像は組み込みの ImageGen で「既存のロゴ・サイドバー・記事内容・サムネイル・タグ下の切り替えボタンを維持し、記事一覧だけを一枚の共通背景にまとめ、記事間を2本の細い横罫線で区切る」と指示し、ライト・ダークを個別に生成した。

2026-10-30 に PC 画像を更新した。ImageGen による修正ではサムネイルの比率が揃わなかったため、[確認用 HTML](./home/preview.html) の `aspect-ratio: 16 / 9` で320×180pxの表示枠を固定し、Playwright で最終画像を書き出した。全6枠（3記事×2配色）の実寸と文章の横方向のはみ出しを検査する。

再生成はリポジトリルートで `node docs/design/home/render.mjs` を実行する。Playwright の Chromium が必要。`reference-light.png`・`reference-dark.png` は更新前の生成画像であり、ヘッダー・サイドバーとサンプル写真の参照用として保持する。確認用 HTML は PC 専用の静的な配置見本で、リンク・切り替えボタンの動作やモバイル対応を実装したサイトではない。サンプル写真は比率を維持して拡大し、16:9枠に中央で切り取って表示する。公開用には16:9の元画像を使用する。

画像は画面デザインの基準であり、サイト実装の完了を示さない。記事タイトル・日付・説明文は表示確認用のサンプル。正式なプロフィール文、アバターの元データ、各リンク先 URL は公開準備時に確認する。

実装方針として、未確定素材は開発用サンプル、未実装導線は操作不可の表示とする。ユーザー提供の GitHub（https://github.com/devegoma）と X（https://x.com/devegoma）は有効なリンクとして使用する。RSS は未実装。アバターは元画像が揃うまでイニシャル、ロゴは単体素材を参考に DM Sans の太字で再現する。フォントは OFL を添えてローカル配信する。

PC・モバイルの両配色と320px幅、Chromium・Firefoxの12表示、JavaScriptなしの移動、本番成果物への下書き除外を確認した。[画面画像・操作手順・検証記録](../../output/issue-15-preview/README.md)を参照する。今回の画面作成をもって親Issue #15全体の完了とはしない。

## タグ一覧・タグ別記事一覧（2026-10-31、Issue #10・#11）

- `/tags/` は「タグから探す」。公開記事があるタグを表示名の日本語ロケール昇順で並べ、公開記事件数を併記する。タグ未選択の案内を表示し、公開タグが0件なら案内とホームへのリンクを表示する。

- 記事は公開日降順、同日なら記事固定名昇順。並べ替え操作は置かない。共通の背景と区切り線、16:9画像、説明・読了時間・記事末尾のタグを表示する。
- 1ページ10件。2ページ目以降は `/tags/<固定名>/page/2/`。表示範囲・現在ページ・前後リンクを示し、存在しない方向は操作不可のテキスト。10件以下ならページ送りを省く。
- 開発サーバーでもタグ画面は下書きを除外する。公開0件・未定義タグや範囲外ページは生成せず404となる。表示名と固定名は既存の中央定義を使う。

- コード・表は領域内で横スクロールできる。引用・補足欄・通常リンク・リストに記事用のスタイルを適用する。

## ホーム画面の採用仕様（2026-10-30 検索付きヘッダー）

今回の改修では、[PC・ライト](../../output/zenn-header-trial/desktop-light-search.png)、[PC・ダーク](../../output/zenn-header-trial/desktop-dark-search.png)、[モバイル・ライト](../../output/zenn-header-trial/mobile-light-search.png)、[モバイル・ダーク](../../output/zenn-header-trial/mobile-dark-search.png)を基準とする。配置と配色については、この節を以下の旧デザインより優先する。

- PC は上段左にコンパクトな文字ロゴ、右に検索欄と配色切り替え、下段に左揃えのナビゲーションを置く。本文は記事一覧を画面中央、プロフィールを左、月別アーカイブとその下のタグを右に置く。プロフィールの上端は記事一覧の枠に揃え、スクロール時は画面上端から24pxの位置に追従する。画面の高さに収まらない場合はサイドバー内でスクロールできる。
- 1199px以下は縦並びの配置とし、上段にロゴ・検索アイコン・配色切り替え、下段に「記事」「タグ」「このブログについて」を置く。本文は横型プロフィール、記事一覧、月別アーカイブ、タグの順にする。プロフィールは通常のスクロールで流れる。
- 最近の記事は最大10件まで表示する。現在の表示確認用サンプルは3件。プロフィールのGitHub・Xリンクは別タブで開く。
- ホームと月別一覧の見出し横に表示順のボタンを置く。初期表示は「↓ 新しい順」（日付の降順）。押すたびに「↑ 古い順」（日付の昇順）と切り替わり、表示中の記事をその場で並べ替える。ホームでは最新10件が対象。JavaScriptが無効な場合は新しい順で表示し、ボタンは操作不可とする。

- 配色切り替えはヘッダー右端。OS 設定への追従、手動選択の優先と保存、保存不可時の動作は維持する。
- ライトは従来の淡いグレーと白、ダークは濃紺の背景とパネル、明るい青緑のアクセントを使う。ロゴの黄色いアポストロフィー、既存フォントと独立した記事画像を維持する。

実装と検証の進捗は [作業計画](../work-plan.md) の最新セクションで管理する。検索処理・本番素材・公開準備は完了に含めない。

### 実装との区別

更新前の PC 画像は組み込みの ImageGen で「既存のロゴ・サイドバー・記事内容・サムネイル・タグ下の切り替えボタンを維持し、記事一覧だけを一枚の共通背景にまとめ、記事間を2本の細い横罫線で区切る」と指示し、ライト・ダークを個別に生成した。

2026-10-30 に PC 画像を更新した。ImageGen による修正ではサムネイルの比率が揃わなかったため、[確認用 HTML](./home/preview.html) の `aspect-ratio: 16 / 9` で320×180pxの表示枠を固定し、Playwright で最終画像を書き出した。全6枠（3記事×2配色）の実寸と文章の横方向のはみ出しを検査する。

再生成はリポジトリルートで `node docs/design/home/render.mjs` を実行する。Playwright の Chromium が必要。`reference-light.png`・`reference-dark.png` は更新前の生成画像であり、ヘッダー・サイドバーとサンプル写真の参照用として保持する。確認用 HTML は PC 専用の静的な配置見本で、リンク・切り替えボタンの動作やモバイル対応を実装したサイトではない。サンプル写真は比率を維持して拡大し、16:9枠に中央で切り取って表示する。公開用には16:9の元画像を使用する。

画像は画面デザインの基準であり、サイト実装の完了を示さない。記事タイトル・日付・説明文は表示確認用のサンプル。正式なプロフィール文、アバターの元データ、各リンク先 URL は公開準備時に確認する。

モバイル案は [モバイル確認用 HTML](./home/mobile-preview.html) から `node docs/design/home/render-mobile.mjs` で再生成する。438px幅・2倍解像度で両配色の画像を書き出し、320・390・438px幅で横方向のはみ出し、プロフィール下のボタン位置、44px以上のタップ領域と配色切り替えを検査する。ロゴ・アバター・SNSアイコンは `reference-light.png`・`reference-dark.png` から比率を維持して切り出し、本文はローカルフォントで描画する。HTMLはデザイン確認用で、カラー切り替えのみ操作できる。今回の更新対象はデザイン資料であり、サイトへの反映は含まない。

実装方針として、未確定素材は開発用サンプル、未実装導線は操作不可の表示とする。ユーザー提供の GitHub（https://github.com/devegoma）と X（https://x.com/devegoma）は有効なリンクとして使用する。RSS は未実装。アバターは元画像が揃うまでイニシャル、ロゴは単体素材を参考に DM Sans の太字で再現する。フォントは OFL を添えてローカル配信する。

# Issue #29 サイトマップと検索向け情報

状態: Q1〜Q7の推奨案と、実装ゴール・タスク分解を2026-11-02に確定。G1〜G4完了。

参照: [Issue #29](https://github.com/devegoma/blog/issues/29)、[要件定義](../requirements.md)、[用語集](../GLOSSARY.md)。

## 目的

公開ページを検索エンジンが発見・取得するためのサイトマップと検索向け情報を、ビルド時に生成する。検索エンジンへの実際の掲載は完了条件にしない。

## 実装全体のゴール

本番ビルドの `/sitemap.xml` に、以下に定義する公開HTMLページの正規URLが漏れなく重複なく掲載されること。掲載ページのHTMLにはページに応じたタイトル・説明文・自身を指すcanonicalがあり、公開から下書きへの差し戻しや削除も次のビルドに反映されること。これらを成果物検査で継続して確認できる状態を完成とする。

## 合意済み事項（2026-11-02）

- 公開URLの基準は `https://blog.devegoma.com/`。
- 検索向け情報はページタイトル・説明文・canonical（正規URL）を対象とする。SNS共有情報は #30、構造化データは今回の対象外とする。
- 既存の月別アーカイブを正式な公開ページとして扱い、サイトマップに含める。
- 既存のタグ別一覧の2ページ目以降も掲載し、ページごとの固有タイトルと自身を指すcanonicalを設定する。
- トップのページ送りは別タスクとする。#29でページ送りを新設しない。
- 下書き・仮URL・削除記事・公開記事0件のタグ・404は掲載しない。
- 公開記事0件でもトップ・プロフィール・タグ一覧は掲載する。公開記事のない月別アーカイブは掲載しない。
- 記事以外の説明文はページ種類に応じた定型文とし、タグ表示名・年月・ページ番号を必要に応じて含める。トップの紹介文と記事の共通概要は維持する。
- サイトマップは `/sitemap.xml` で公開する。URLのみを掲載し、`lastmod` などの付加情報は出力しない。
- `/robots.txt` にサイトマップの絶対URLを記載する。
- 404・開発用下書きプレビューは `noindex` とし、canonicalは出力しない。下書き本文を本番で生成しない方針は維持する。

## 公開ページと正規URL

| ページ                    | 掲載条件                               | 正規URLのパス                 |
| ------------------------- | -------------------------------------- | ----------------------------- |
| トップ                    | 常に掲載                               | `/`                           |
| プロフィール              | 常に掲載                               | `/about/`                     |
| タグ一覧                  | 常に掲載                               | `/tags/`                      |
| 記事                      | 公開記事のみ                           | `/posts/<記事パス>/`          |
| タグ別一覧の先頭          | 公開記事1件以上                        | `/tags/<固定名>/`             |
| タグ別一覧の2ページ目以降 | 公開記事に対応するページが存在する場合 | `/tags/<固定名>/page/<番号>/` |
| 月別アーカイブ            | 該当月の公開記事1件以上                | `/archives/YYYY-MM/`          |

すべて `https://blog.devegoma.com/` を基準とする絶対URL・末尾スラッシュありとし、クエリやフラグメントを含めない。ページ送りの先頭URLへの集約はしない。RSS・robots.txt・サイトマップ自体はHTMLページの掲載集合に含めない。生成済みファイルを無条件に列挙せず、上記の公開範囲と一致させる。

## 検索向け情報

- タイトルは既存のサイト名付き形式を維持し、ページの役割を表す。タグ別一覧の2ページ目以降にはページ番号を含める。
- トップの説明文は既存のサイト紹介文を使う。
- 記事の説明文は #27 の共通概要を使い、抽出規則は変更しない。
- プロフィールはブログと執筆者の紹介、タグ一覧はタグから記事を探すページであることを説明する。
- タグ別一覧はタグ表示名、月別アーカイブは対象の年月を説明文に含める。2ページ目以降にはページ番号も含める。
- 掲載対象の各HTMLにタイトル・説明文・canonicalをそれぞれ1つ出力し、canonicalをサイトマップの掲載URLと一致させる。
- `robots.txt` はサイト全体のクロールを妨げず、`Sitemap: https://blog.devegoma.com/sitemap.xml` を案内する。
- 404と開発用下書きプレビューには `noindex` を出力し、canonicalを出力しない。`noindex` を下書き本文の本番出力防止の代わりにはしない。

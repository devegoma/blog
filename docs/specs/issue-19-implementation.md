# Issue #19 記事形式とMDX読み込み

対象: [Issue #19](https://github.com/devegoma/blog/issues/19)、2026-11-01。

## 実装

`src/content.config.ts` の `posts` コレクションが `src/content/posts/**/*.mdx` を読み込む。入力の型・既定値は同じスキーマを通し、`.md` は対象外。`generateId` は区切りを `/` に統一し、各セグメントを検証して末尾の `.mdx` だけを除く。`index` を含む階層を維持し、`slug` は値にかかわらず拒否する。

`src/data/posts.ts` の `getPosts()` が詳細・ホーム・タグ・アーカイブで共通の記事データを返す。公開と下書きは同じ戻り値の型を使う。`id` と `href` はファイルパスから導出し、frontmatterには入力しない。

## 検証

`pnpm test:content` は `test-results/content-*` にソースの一時コピーを作り、実際のAstroビルドで共通取得結果とHTMLを確認する。検証専用JSONページは一時コピー内だけに生成され、通常のサイトには追加されない。

- 最小の公開記事、タイトルだけの下書き、明示的な下書き、任意項目と既定値。
- 元ファイルパス・MDX本文・未指定の説明文の保持。
- 直下・複数階層・同名ファイル・同じフォルダの複数記事・`index` のURLとホームのリンク。
- タイトル変更後のURL維持、`.md` の除外。
- 大文字・日本語・空白・アンダースコア・先頭/末尾/連続ハイフンをファイル名・フォルダ名の両方で拒否。
- 空白タイトル、項目の型違反、タグ要素の型違反、読了時間の正整数制約、画像パス、`slug: null` をファイル名・原因付きで拒否。

`pnpm test:publication` はタグからの記事リンク、下書き化・削除後の出力除外と開発プレビューも確認する。`pnpm test:tags` は既存のタグ画面との接続を確認する。

# Issue #25 共通デザイン

仕様元: [Issue #25](https://github.com/devegoma/blog/issues/25)（2026-11-06の最終合意）。本書は過去のデザイン案に優先する。

## 方針と範囲

現在の独自テーマのみを使用する。既存テーマの採用・選定保留の方針は取り下げる。現在の見た目を基本とし、使い勝手や画面間の不一致など、具体的な理由のある箇所を変更する。

読者が最新の記事に興味を持って読み始めることを優先し、タグやプロフィールは次の行動とする。各画面固有の配置は、それぞれの画面Issueで扱う。

正式な自己紹介文・アバター素材・画像の利用条件は確認済みで、反映と検証は [PR #62](https://github.com/devegoma/blog/pull/62) で完了した。既存のGitHub・XのURLを維持する。

## 確定仕様

### 検索

PCの検索バー、モバイルの検索アイコン、「検索は準備中」の開閉画面を一式削除する。現時点では検索導入を約束しない。タグや記事一覧で探しにくくなり、必要性が明確になった段階で再検討する。

### 共通ヘッダーとナビゲーション

ホーム、記事詳細、タグ関連、プロフィール、月別一覧、404画面で2段ヘッダーを共通化する。上段は左にロゴ、右に配色切り替え、下段は「記事」「タグ」「このブログについて」とする。ロゴと「記事」はホームへ移動する。

ヘッダーは固定せず、スクロールすると画面外に流れる。1199px以下でモバイル向けの表示に切り替える。

| 画面                                      | 選択表示           |
| ----------------------------------------- | ------------------ |
| ホーム・2ページ目以降・月別一覧・記事詳細 | 記事               |
| タグ一覧・タグ別記事一覧                  | タグ               |
| プロフィール                              | このブログについて |
| 404                                       | なし               |

### 配色と操作

現在のライト・ダーク配色を全画面で共通化する。画面ごとの独自配色は設けない。初回は端末の配色設定に従い、手動選択がない間は端末の設定変更に追従する。

手動で切り替えた後は選択を保存し、次回も優先する。保存できない場合も、開いている画面では切り替えられる。操作はライト・ダークの切り替えのみとし、手動選択後に端末設定への追従を再開する操作は提供しない。

### フォント

欧文はDM Sans、日本語はNoto Sans JP、日付やコードなどは等幅のIBM Plex Monoを継続し、サイト内から配信する。

- 各画面のヘッダーと操作: 検索UIの不在、リンク先と選択表示、2段配置、1199pxの切り替え、スクロールで画面外へ流れること。

- ページ表示とフォント通信: 指定フォントの適用、サイト内からの配信。

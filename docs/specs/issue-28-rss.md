`scripts/check-rss.mjs` は `test-results/` へ記事とソースの隔離コピーを作って検証する。既存の公開判定テストは成果物の全ファイルを検査するため、RSS追加後も下書き情報の混入確認に利用できる。

## 実装方式

- [Astro公式RSSレシピ](https://docs.astro.build/en/recipes/rss/)に従い、`@astrojs/rss@4.0.19` を利用する。`src/pages/rss.xml.ts` から公開判定・概要・順序が共通化された記事データを渡し、静的ビルド時に生成する。
- XMLの検証は `sax@1.6.1` のstrictモードで実際に解析し、記事項目の値と件数を確認する。同パッケージは既存の間接依存と同じ版を直接の開発依存として宣言した。
- `pnpm test:rss` は隔離した一時コピーで検証する。`pnpm test` にも組み込んだ。ブラウザテストは利用者が操作する購読導線と、HTMLに出力した自動検出情報を検証する。

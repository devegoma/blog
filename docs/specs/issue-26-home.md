# Issue #26 ホームの実データ表示とページ送り

対象: <https://github.com/devegoma/blog/issues/26>

共通デザインは [Issue #25の確定仕様](./issue-25-common-design.md) を優先する。検索準備中UIは同Issueで削除対象となり、正式プロフィール素材はPR #62で反映済み。以下の検索準備中UIの記述と範囲外事項は、Issue #26実施時点の記録として保持する。

## 2026-11-07の変更: ホームの並べ替えを復元

ユーザーの指示により、ホームでも従来どおりボタンのクリック・Enter・Spaceで「新しい順 ⇔ 古い順」を切り替える。初期表示は新しい順とし、表示中のページ内の記事を並べ替える。ページ移動時は新しい順に戻る。ページ送りと月別一覧の既存動作は維持する。以下の新しい順固定・切り替え撤去の記述は、Issue #26実施時点の履歴であり、本節を優先する。

ブラウザ上のボタン操作と記事の表示順をテスト境界としてユーザー確認済み。ホームにボタンが存在せずテストが失敗することを確認した後、固定表示にする条件分岐を除き、既存の並べ替え処理を復元して同じテストの成功を確認した。

復元後の検証: `pnpm test:home`、Lint、型チェック、ビルド、変更ファイルのPrettier、差分チェックが成功。`pnpm exec playwright test --workers=4`はChromium／Firefox × 3サイズで180件成功、重複検証を避ける条件で12件スキップ、失敗0件。ホームと月別一覧の切り替え操作を1つのテストで確認するよう統合したため、共通デザイン対応時より総テスト数は6件減っている。全公開記事の取得順やページ送りの方式は変更していない。

## 合意した仕様（Issue #26実施時点）

- ホームは公開記事を公開日降順、同日は記事の固定名昇順で表示する。
- 1ページ10件。1ページ目は `/`、2ページ目以降は `/page/2/` 形式とする。
- 画像未指定の記事は画像を表示しない。
- ホームの「古い順」切り替えを撤去する。
- 無効な「すべての記事を見る」を、前後のページへのリンク・現在／総ページ数・表示件数範囲に置き換える。10件以下ではページ送りを表示しない。
- プロフィール・タグ・RSSへのリンクを確認する。プロフィールデータの共通化と正式な紹介文・画像は #25 の範囲とする。
- サンプルは今回残す。サンプル記事・画像の公開成果物からの除外と混入検査は、公開前の必須タスクとして別管理する。
- 正式記事の執筆と本番デプロイは含めない。
- 月別アーカイブは引き続き月内の記事を全件表示する。
- 月別アーカイブの既存の並べ替え操作は維持する。ホームのページ送りとは分離する。
- 0件のホームは「公開記事はまだありません。」と表示する。
- 2ページ目以降のタイトルは「記事 - Nページ目」、説明文は「公開記事の一覧です（Nページ目）。」とし、それぞれのURLをcanonicalにする。

## 実装順序とゴール

1. **表示と導線**: 既存の実データ表示を確認し、ホームを新しい順に固定する。画像なし表示、プロフィール・タグ・RSSへのリンクが正しく機能する。
2. **ページ送り**: 合意したURLと操作で全公開記事を10件ずつたどれる。0件・10件・11件・21件で件数、順序、ページ境界、前後リンクが正しく、記事の抜けや重複がない。
3. **検索向け出力**: 各ページのcanonicalとサイトマップを接続する。生成HTMLとXMLのURLが一致し、存在しないページを掲載しない。
4. **全体検証と記録**: モバイル、ライト／ダーク、検索準備中UI、タグ・月別アーカイブを含む回帰検証を行い、結果と別タスクの境界を記録する。

## TDDで検証する公開境界（合意済み）

内部関数やコンポーネントの構造を直接検証せず、以下の2つを検証対象とする。

1. **ブラウザに表示されるページとリンク操作**: 実際に表示される記事・並び順・画像・導線・ページ送り、モバイルの配置、配色、検索準備中UIを既存のPlaywright検証で確認する。
2. **記事入力に対する本番ビルドの公開成果物**: 隔離した検証用記事を用意して実際にビルドし、0件・10件・11件・21件の生成HTML、記事の振り分け、前後リンク、canonical、サイトマップ、不要なページが生成されないことを確認する。

2026-11-04に上記の境界で合意。実装順に1つの振る舞いずつ、失敗する検証 → 最小実装 → 成功確認を繰り返す。

1〜4は順に実装・検証を完了した。

## 公開前に必要な別タスク

- [ ] サンプル記事・画像を通常の公開成果物から除外する。
- [ ] 記事一覧・記事ページ・RSS・サイトマップなどにサンプルが混入しないことを検証する。
- [ ] 元のIssueのサンプル混入防止の完了条件を、この別タスクへの移管が分かる記載に変更する。GitHub上の変更は未実施。

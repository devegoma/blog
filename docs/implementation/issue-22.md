# Issue #22 公開対象の共通化

- getPosts() は開発・本番とも明示的な draft: false の記事だけを返す。ホーム、月別一覧、タグ一覧・タグページ、公開記事の前後移動がこの境界を使用する。
- 下書き取得は記事詳細だけで明示的に指定する。includeDrafts: true でも本番ビルドでは下書きを返さない。
- RSS・サイトマップは #17 配下で実装する。取得には同じ getPosts() を使用し、独自の公開判定を追加しない。
- 検証: pnpm test:publication で本番除外・開発時の一覧除外と詳細プレビューを確認する。実行結果は検証後に追記する。

2026-11-01: pnpm test:publication 成功。相対パスURL、異常データ、公開後の下書き変更・削除、本番除外、開発詳細と一覧の分離を実ビルドで確認。

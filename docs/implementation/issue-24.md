# Issue #24 非公開化・成果物検査

#23（その前提の #22 を含む）に依存する。pnpm test:publication はCIの pnpm test から実行される。

- 公開、明示的な下書き、状態未指定、タグなしでの再公開、削除を同じ一時記事と同じ出力先で順に検証する。
- 公開時のHTTP 200、下書き化・状態省略・削除後のHTTP 404を、本番ビルドを配信する専用 preview プロセスで検証する。
- 本文・タイトル・説明・URLの印が、全成果物（HTML・JavaScript・JSON・XML等、拡張子で限定しない）へ残っていないか検査する。タグ・月別一覧のファイル不在も確認する。
- 一時的な取得契約のJSONエンドポイントを生成し、includeDrafts: true で呼んでも本番では公開対象だけが取得できることを確認する。検証後は記事・エンドポイントを削除する。
- RSS・サイトマップ自体は #17 配下の未実装機能。実装後は生成されたXMLも自動的に漏出検査に含まれるが、現時点ではそれらの実ルートとの結合確認は未実施。取得には getPosts() を使い、公開時に公開記事の収載と未公開記事の除外も確認すること。配信済みキャッシュの回収やCloudflareへの反映は対象外。

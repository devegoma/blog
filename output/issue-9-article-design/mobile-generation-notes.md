# モバイル生成補足

組み込み ImageGen を使用。`prompts.md` のモバイル各色を基に、以下を追加指定した。

- 幅390 CSS px相当のスマートフォン、縦横比1:3。1行は日本語約18文字。
- タイトルは2行。ロゴは `devegoma’s blog` の全文を表示する。
- 全文を縮小して収めず、記事上部からコードブロック冒頭までの範囲を描く。
- 残りの本文・記事下プロフィールは画像の下方に続く想定。
- ヘッダーは浮いたカードにせずページ幅いっぱい。
- 左右16px、記事内側20pxの余白を想定。

ダークは上記の追加指定で生成。ライトの最初の結果はタブレットに近い密度・ロゴ欠落だったため `article-mobile-light-v1.png` として保存し、ダーク画像を構造参照にしてライトを1回再生成した。最終ファイルは `article-mobile-light.png` と `article-mobile-dark.png`。どちらも727×2164px。本文上の折りたたみ目次、記事内画像、本文・引用・コード冒頭を目視確認した。全ページ画像ではなく上部の配置見本であり、プロフィール・表・末尾リンクは範囲外。

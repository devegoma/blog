## 画面仕様

- 共通ヘッダー、配色切り替え、本文、プロフィール、目次をそのまま使用する。PCは3列、1199px以下は1列。
- 記事パネルの先頭に淡いアクセント色の帯を置き、「下書き」「開発プレビュー限定」と本番サイトへ出力されない旨を表示する。
- 日付がある下書きは「公開日（設定値）」とする。日付なしの場合は補完しない。
- 下書きのタグは表示だけにする。下書き専用タグのページは生成されないため、移動リンクを設けない。公開記事のタグリンクは従来どおり。
- 下書きには前後記事ナビを表示しない。記事末尾の「記事一覧に戻る」は利用できる。

## 手元で開く

`pnpm dev --host 127.0.0.1` を起動し、表示されたローカルURLの `/posts/draft-preview/` を開く。任意の記事も `src/content/posts/` から拡張子を除いた相対パスで開ける。例: `notes/example.mdx` は `/posts/notes/example/`。`draft: true` または状態省略で下書きになる。プレビューURLを共有・配信する機能は追加していない。

画像中の本文は検証専用の一時記事。検証終了時に削除するため、この例の記事URLは常設しない。

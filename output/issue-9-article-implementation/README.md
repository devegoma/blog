## 実装内容

共通ヘッダー・プロフィールを既存ホームから抽出した。PCは3列、1199px以下は本文と末尾プロフィールの1列。h2・h3から生成する目次はPCで追従、モバイルで折りたたみ。スクロール位置に応じて目次を強調する。標準アンカー・details・キーボードフォーカスで、JavaScriptが無効でも本文移動できる。

記事はAstroのContent Collectionsに移し、公開記事の選択を `getPosts()` に集約した。ホーム・月別一覧・記事詳細・タグは同じ選択結果を使う。固定名はfrontmatterの `slug`、公開状態は `draft`。省略時は下書きとして扱う。公開日・更新日は日本時間で検証し、固定名重複も生成前に止める。

説明文の未入力時は現在はタイトルを使う。RSSの概要抽出・RSS配信、一覧のページ送り、公開サイトの404案内画面、SNS共有情報の整備は別の公開準備として残る。タグ導線は動作するが、タグ一覧独自のデザイン検討は今回の対象外。記事・画像・プロフィールは引き続き表示確認用サンプルである。

## 最下部で目次が切り替わらない不具合の修正

1280×720pxの `/posts/automation/` で再現した。ページ最下部でも最後の「まとめ」は画面上端から約335pxの位置にあり、見出しの切り替え基準160pxに届かず、一つ前の目次が選択されたままだった。余白を一時的に400px追加すると最後の目次が選択され、余白を戻すと再発することから、見出しとリンクの不一致やスクロールイベントの欠落ではなく、スクロール可能な距離の不足と確認した。

スクロールできるページの最下部では最後の見出しを選択する。上へ戻れば従来の見出し位置の判定に戻る。端数のスクロール位置は1pxの差を許容し、画面内に収まる短いページの初期表示（見出し指定なし）では先頭の項目を維持する。画面サイズ変更時も再判定する。

回帰テストは、修正前に「まとめ」の `aria-current` が付かず失敗することを確認してから追加した。最下部・上端への往復、短い末尾、スクロール不要なページ、PC・モバイルの両目次を検証する。

## 短い記事で途中の目次を選択できない不具合の修正（2026-10-31）

`/posts/before-coding/` の「小さく試す」をクリックするとURLは正しく変わる一方、移動が最下部に制限され、「振り返りを残す」が選択されていた。1280×720pxではスクロール上限451px、1920×1080pxでは46pxで再現した。通常のスクロールでも先頭と最後しか選択されず、途中の項目が飛ばされていた。

クリック・URL指定・ブラウザー履歴で明示した見出しは、その移動先のスクロール位置にいる間は優先して選択する。実際にスクロール位置が変われば通常の判定へ戻す。同じ目次の再クリックや、スクロール不要な記事も扱う。

通常の判定では、末尾の複数見出しが上端160pxまで届かない場合に、その切り替え位置を残りのスクロール範囲へ収める。手前の到達可能な見出しの判定位置は維持する。これにより、短い記事でも先頭・途中・末尾を順に選択でき、最下部で最後の見出しを選ぶ既存の動作も維持する。

修正前に、クリックした途中見出しが選択されない回帰テストと、通常スクロールで途中見出しが飛ばされる回帰テストが失敗することを確認した。修正後は通常スクロール・同じ項目の再クリック・再読み込み・戻る／進む・短い記事の6構成の回帰テストが成功した。

最終検証は記事関連36テストが26.2秒で成功。Lint・型チェック・ビルド・変更ファイルの整形確認も成功した。

## PR #38 レビュー対応（2026-10-31）

[レビュー指摘](https://github.com/devegoma/blog/pull/38#discussion_r4427571507): `.md` はMDXのコンポーネント差し替えの対象にならず、コードのコピーと表の横スクロール用コンテナーが適用されない。

レビューの対応案に従い、記事形式を既存記事と同じ `.mdx` のみに統一した。Content Collectionsの読み込み対象・ファイル名からのID生成・執筆手順を揃えた。通常のMarkdown構文は `.mdx` 内で使用できる。

公開ライフサイクル検証へ、有効な公開メタ情報を持つ `.md` ファイルを一時的に配置しても、記事ページとトップの記事一覧に出力されないことを確認する回帰チェックを追加した。修正前に失敗することを確認済み。

修正後は公開ライフサイクル検証・本番ビルド・Lint・型チェック・追跡対象ファイルの整形確認が成功した。Chromium／Firefoxの3サイズの全90テストが49.1秒で成功した。

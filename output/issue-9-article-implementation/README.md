# Issue #9 記事詳細の実装記録

2026-10-30。ユーザーが了承した [デザイン案](../issue-9-article-design/DESIGN.md) に沿って実装した。検討画像のピクセル再現ではなく、現行ホームの色・フォント・共通ヘッダーを使用する。

## 確認するページ

- `/posts/automation/`: 更新日・複数タグ・目次・画像・表・引用・色分けコード・補足欄。
- `/posts/sample/`: 従来のURLを維持した読書メモ。ホームの表示名と記事タイトルを統一した。
- `/posts/before-coding/`: 更新日・タグなし。
- `/tags/` と `/tags/typescript/`: 記事から移動できるタグ導線。表示名と固定名は `src/data/tags.ts` で管理する。
- 開発時限定 `/posts/draft-preview/`: 公開状態・日付・固定名・説明文を省略した下書き。本番では404。

## 実装内容

共通ヘッダー・プロフィールを既存ホームから抽出した。PCは3列、1199px以下は本文と末尾プロフィールの1列。h2・h3から生成する目次はPCで追従、モバイルで折りたたみ。スクロール位置に応じて目次を強調する。標準アンカー・details・キーボードフォーカスで、JavaScriptが無効でも本文移動できる。

記事はAstroのContent Collectionsに移し、公開記事の選択を `getPosts()` に集約した。ホーム・月別一覧・記事詳細・タグは同じ選択結果を使う。固定名はfrontmatterの `slug`、公開状態は `draft`。省略時は下書きとして扱う。公開日・更新日は日本時間で検証し、固定名重複も生成前に止める。

説明文の未入力時は現在はタイトルを使う。RSSの概要抽出・RSS配信、一覧のページ送り、公開サイトの404案内画面、SNS共有情報の整備は別の公開準備として残る。タグ導線は動作するが、タグ一覧独自のデザイン検討は今回の対象外。記事・画像・プロフィールは引き続き表示確認用サンプルである。

## 最下部で目次が切り替わらない不具合の修正

1280×720pxの `/posts/automation/` で再現した。ページ最下部でも最後の「まとめ」は画面上端から約335pxの位置にあり、見出しの切り替え基準160pxに届かず、一つ前の目次が選択されたままだった。余白を一時的に400px追加すると最後の目次が選択され、余白を戻すと再発することから、見出しとリンクの不一致やスクロールイベントの欠落ではなく、スクロール可能な距離の不足と確認した。

スクロールできるページの最下部では最後の見出しを選択する。上へ戻れば従来の見出し位置の判定に戻る。端数のスクロール位置は1pxの差を許容し、画面内に収まる短いページでは先頭の項目を維持する。画面サイズ変更時も再判定する。

回帰テストは、修正前に「まとめ」の `aria-current` が付かず失敗することを確認してから追加した。最下部・上端への往復、短い末尾、スクロール不要なページ、PC・モバイルの両目次を検証する。

修正後はChromium／Firefox × 1280・1920・390pxの記事関連24テストが21.6秒で成功した。Lint・型チェック・本番ビルド・変更ファイルの整形確認も成功した。

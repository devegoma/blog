参考: https://zenn.dev/ （2026-10-30 確認）

## 配置

- 上段の左に既存のロゴを小さく配置。
- 上段の右端にカラー切り替えボタンを配置。
- 下段に「記事」「タグ」「このブログについて」を横並びで配置。
- 選択中の「記事」は青緑色の下線で示す。
- ヘッダーと本文の左右の位置をそろえる。
- プロフィール、タグ、記事一覧は既存デザインを引き継ぐ。

## ダークカラー案

検索付きのデスクトップ版・モバイル版をそれぞれ参照し、配置を保ったままダークカラーに変更しています。Built-in ImageGen による画像編集です。

- 背景: 濃紺 `#101c24`
- パネル: `#182934`
- 文字: `#edf5f7`、補助文字 `#a5bac4`
- 境界線: `#304550`
- アクセント: 青緑 `#65d2dd`
- 黄色のアポストロフィーと記事画像の色を維持。
- ライトカラーへ戻す操作を示すため、テーマ切り替えは太陽アイコンに変更。

上記は生成時の指定色です。画像内の厳密な色値を保証するものではありません。

## 検索欄を追加した案

`desktop-light-search.png` は、上段右側のカラー切り替えボタンの左隣に検索欄を追加した案です。
虫眼鏡アイコンと「記事を検索…」を表示し、幅約300px、高さ40pxを目安に配置しています。
画像としての試作で、検索機能の実装は含みません。

編集プロンプト: 既存の desktop-light.png を参照し、上段右側の月アイコンの左隣に、虫眼鏡と「記事を検索…」を含む検索欄だけを追加する。淡い青灰色の背景、細い境界線、10pxの角丸、月アイコンとの間隔16px。ロゴ、ナビゲーション、本文、画像、配色、余白、キャンバス寸法は維持する。Built-in ImageGen を使用。

## モバイル案

`mobile-light-search.png` は幅390px程度を想定した検索付きトップページの試作です。

- 上段: 左にロゴ、右に検索アイコンとカラー切り替え。
- 下段: 記事・タグ・このブログについての横並びナビゲーション。
- 検索はアイコンを押して入力欄を開く想定。画像は閉じた状態。
- プロフィールはコンパクトな横型カードにし、記事一覧を1列に配置。
- タグ一覧は記事一覧の下へ移動。

Built-in ImageGen で desktop-light-search.png を参照して生成。
プロンプト要旨: 390px幅の縦長モバイル画面として、既存のロゴ・青緑の配色・記事3件・サムネイルを維持する。上段64pxに幅約220pxのロゴと40pxの検索・月アイコン、下段48pxにナビを置く。左右16pxの余白を取り、プロフィールを横型、記事を1列にまとめる。端末枠や注釈は付けない。検索の開閉や検索処理は未実装。

## 初回案の生成条件

Built-in ImageGen による UI モックアップ。
参照画像: docs/design/home/desktop-light.png、docs/design/logo/wordmark-light.png。

プロンプト要旨: 既存の青緑・淡いグレー・黄色のアポストロフィーを保つ。Zenn の2段ヘッダーを参考に、左上に幅約300pxのロゴ、右上に44pxの月アイコンのテーマ切り替え、その下に横並びのナビゲーションを置く。幅1440pxのデスクトップ画面で、中央の本文幅約1120pxに配置をそろえる。巨大なロゴをなくし、左のプロフィールとタグ、右の記事3件は継承する。検索やログインは追加しない。ブラウザー枠や注釈を含めない。

読んだ本の内容を、自分の言葉で短く書き残すようにしています。すべてを覚えようとするより、あとから見つけられる形を作るほうが続けやすくなりました。

![夜景の見える机に置いた本と読書メモ](/images/sample-reading.png)

## メモに残すこと

印象に残った一節だけでなく、なぜ気になったのか、次に何を試したいのかを書きます。

- 本のタイトルと著者
- 気になったことを、自分の言葉で
- 日々の作業で試したいこと

## コード

記事内のコードや表も、メモの一部として記録できます。

```typescript
const message: string = "Hello, Astro!";
console.log(message);
```

## 表と引用

| ツール     | 用途                 |
| ---------- | -------------------- |
| Obsidian   | 読書メモと関連づけ   |
| Astro      | 記録の公開           |
| Playwright | ブラウザでの動作確認 |

> 学んだことを記録していきます。

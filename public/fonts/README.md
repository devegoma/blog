# フォント

Google Fonts の公式リポジトリから取得したフォントをローカル配信する。ブラウザから外部フォントサービスへの通信は行わない。

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Noto Sans JP: https://github.com/google/fonts/tree/main/ofl/notosansjp
- IBM Plex Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

各フォントの SIL Open Font License は同ディレクトリの `OFL-*.txt` に保存している。バイナリは加工していない。
